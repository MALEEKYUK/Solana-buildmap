# Solana Buildmap
Pick what you want to build on Solana, get the repos and docs to start with.

## Deploy on Railway
1. Push this folder to a GitHub repo.
2. In Railway: New Project > Deploy from GitHub repo > select it.
3. Railway detects Node and runs `npm start`. No variables needed (it reads PORT automatically).
4. Settings > Networking > Generate Domain.

Run locally: `npm start` then open http://localhost:3000
